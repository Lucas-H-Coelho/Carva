# Carva Dashboard Engine

## Responsabilidade

Painel admin com React SPA, métricas, CRUD de produtos/serviços, agendamentos, clientes e temas.

## Namespace

`Carva::Dashboard`

## Dependências

- `carva_core`
- Todas as outras engines (para dados)
