# Carva Storefront Engine

## Responsabilidade

Storefronts públicas, catálogo de produtos/serviços, agendamentos e checkout.

## Namespace

`Carva::Storefront`

## Dependências

- `carva_core`
- `carva_theme_engine`
- `carva_inventory`
